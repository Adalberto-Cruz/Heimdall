# Instruções para assistentes de IA

Antes de qualquer tarefa neste repositório, leia [`CONTEXTO_HEIMDALL.md`](CONTEXTO_HEIMDALL.md).

Ele define a visão do projeto, os públicos, os elos da cadeia, o papel de cada disciplina, o contrato JSON e as regras que toda entrega precisa seguir. Nenhuma parte do Heimdall é um trabalho isolado: todo código, relatório, slide ou roteiro precisa dizer de onde vêm os dados, para qual peça vai o resultado e qual elo da cadeia ele cobre.

Regras que não podem ser quebradas:

- Use sempre o nome Heimdall e o contrato JSON único.
- Use apenas dados reais com fonte citada.
- Não coloque a IA como autora ou coautora de commits.
- Não inclua o `.env` nem outros segredos em commits ou arquivos de entrega.
